# Project Rules (POC Mode)

This is a personal greenfield Proof of Concept (POC). 

Speed to a working prototype is the ONLY priority.

## Strict Constraints:

- NO benchmarks, performance profiling, or premature optimization.

- NO extra markdown files, roadmaps, architecture diagrams, or review reports.

- NO automated tests or CI/CD pipelines unless explicitly requested.

- Build the absolute minimum working code to satisfy the prompt.

- Do not create abstractions for single-use logic; keep it all simple and flat.

- Ask directly if an external dependency is strictly necessary before installing it.
